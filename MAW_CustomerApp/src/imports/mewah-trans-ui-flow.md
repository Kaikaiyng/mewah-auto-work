Design a modern mobile app UI for a private customer car service application called “Mewah Trans AutoCare”.

This app is only for registered customers of Mewah Trans. Users cannot sign up themselves. Customer accounts are created by the Mewah Trans company and customers receive login credentials to access the app.

Target users:
Car owners who service their vehicles at Mewah Trans Service Centre.

Design style:

Clean modern automotive style

Professional and trustworthy

Minimal and easy to use

Smooth service booking experience

Color theme: dark blue, white, light grey

Rounded cards and modern icons

Friendly UI with simple navigation

Mobile app layout for iOS and Android

Support bilingual interface (English and Chinese)

Generate a complete mobile UI flow including the following screens.

Login Screen
Include:

App logo

Phone or Email login

Password field

Login button

“Contact Support” link

Small note: “Account provided by Mewah Trans”

Home Dashboard
Show vehicle and service information.

Sections:

Welcome message

Registered vehicle card (Car model, plate number, mileage)

Upcoming service reminder

Latest booking status

Quick action buttons:

Book Service

Buy Spare Parts

Contact Support

Service Booking Screen
Step by step booking flow.

Step 1
Select service type:

Car Maintenance

Vehicle Repair

Spare Parts Purchase

Step 2
Select service centre location.

Step 3
Select available date and time using a calendar interface.

Step 4
Add notes or service requests.

Step 5
Confirm booking summary.

Booking History Screen
Show list of past and upcoming bookings.

Each booking card should show:

Service date

Service type

Booking status (Upcoming / Completed)

Total price

Booking Detail Screen
When a booking is opened, show full details including invoice.

Include:

Vehicle information

Service centre location

Service description

Mechanic notes

Invoice section should include:

Service items

Spare parts used

Labour cost

Total price

Include a button to download the invoice as PDF.

Spare Parts Page
Allow users to browse common spare parts.

Categories:

Engine Parts

Brake Parts

Oil and Filters

Car Accessories

Each product card should show:

Product image

Product name

Price

Add to booking button

Service Reminder Screen
Show next recommended service date and mileage reminder.

Allow users to:

Set reminder notification

Book service directly from reminder

Contact Support Screen
Include options:

Call Mewah Trans

WhatsApp Support

Send Message

View Service Centre Map

Profile Screen
Show customer information including:

Customer name

Registered vehicle

Contact information

Buttons:

Edit profile

View invoices

Logout

Navigation Structure
Use bottom navigation bar with the following tabs:

Home

Bookings

Parts

Reminders

Profile

Use modern UI components including:

Card layouts

Clean icons

Booking progress indicator

Notification badges

Calendar booking interface

Generate a complete connected mobile UI flow for this application.
